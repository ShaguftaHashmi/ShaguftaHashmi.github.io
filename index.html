Python Master Study Guide

1. Python Setup, Variables & Data Types

Python is an interpreted, high-level language. Variables are created the moment you assign a value to them.

# Data Types
x = 5             # int
y = 3.14          # float
name = "Alice"    # str
is_active = True  # bool

2. Operators & String Operations

Python supports arithmetic (+, -, *, /, //, %), comparison, and logical operators.

text = "Hello World"
print(text.upper())       # HELLO WORLD
print(text[0:5])          # Hello (Slicing)
print(text + "!")         # Concatenation

3. Lists & Tuples

Lists are ordered, mutable collections. Tuples are ordered, immutable collections.

# List (Mutable)
fruits = ["apple", "banana"]
fruits.append("cherry")

# Tuple (Immutable)
coordinates = (10, 20)

4. Sets, Dictionaries & Nested Structures

Sets store unique items. Dictionaries store key-value pairs.

unique_numbers = {1, 2, 3, 3} # Result: {1, 2, 3}
user = {
    "name": "Bob",
    "age": 25,
    "skills": ["Python", "HTML"] # Nested List
}

5. Conditions & Loops

# Condition
if age >= 18:
    print("Adult")
elif age > 12:
    print("Teen")
else:
    print("Child")

# Loops
for i in range(3):
    print(i) # Prints 0, 1, 2

6. Functions

Functions are blocks of reusable code defined using the def keyword.

def greet(name="Guest"):
    return f"Hello, {name}!"

print(greet("Alice"))

7. File Handling, List Comprehension, Lambda

# List Comprehension (Short way to create lists)
squares = [x**2 for x in range(5)]

# Lambda (Anonymous function)
add = lambda a, b: a + b

# File Handling
with open("data.txt", "w") as file:
    file.write("Hello File!")

8. Exception Handling

Used to handle runtime errors gracefully without crashing the program.

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")
finally:
    print("Execution complete.")

9. Object-Oriented Programming (OOPS)

Python supports classes, objects, and inheritance.

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Woof!"

10. Polymorphism, JSON & APIs

Polymorphism allows methods to do different things based on the object. JSON/APIs are used for data exchange.

import json
import requests

# JSON Parsing
data = '{"name": "Alice"}'
parsed = json.loads(data)

# API Request (Requires 'requests' library)
response = requests.get("https://api.github.com")
print(response.status_code)
